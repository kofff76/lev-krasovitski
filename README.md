# Лев Красовицкий — сайт (редакция 2)

Статический сайт, 7 страниц. Откройте index.html или разместите всю папку на GitHub Pages.

- `press.html` — материалы прессы со ссылками на внешние публикации.
- `media.html` — галерея, 2 исходных видео и ссылка на аудиозапись «Калинка».
- `schedule.html` — афиша без вымышленных дат.
- Все видео находятся в `assets/video`.
- Сведения о биографии и контактах основаны на предоставленном резюме.
- Заголовки видео оставлены нейтральными: названия произведений требуют подтверждения.
- «Калинка» воспроизводится через внешний музыкальный сервис (самого аудиофайла не было).
- Внешние ссылки на публикации могут изменяться владельцами сайтов.
